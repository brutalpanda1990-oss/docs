## Présentation / Overview

VesselIQ utilise un système de types TypeScript strict pour garantir la cohérence des données à travers l'application. Cette page documente les types principaux définis dans `types.ts` et le dossier `types/`.

*VesselIQ uses a strict TypeScript type system to ensure data consistency across the application. This page documents the main types defined in `types.ts` and the `types/` folder.*

---

## Types principaux / Main Types

### Supplier (Fournisseur)

```typescript
interface Supplier {
    id: string;
    name: string;
    email?: string;
    phone?: string;
    fax?: string;
    website?: string;
    streetAddress?: string;
    city?: string;
    postalCode?: string;
    country?: string;
    type?: string;           // OEM, Distributeur, Agent...
    categorie?: string;      // Marine, Industriel...
    marque?: string;         // Marques représentées
    specialites?: string[];  // Liste spécialités
    certifications?: string[];
    contact?: { name?: string; email?: string; phone?: string };
    status?: 'actif' | 'inactif';
    rating?: number;         // Note 1-5
    delaiLivraison?: string;
    conditionsPaiement?: string;
    devise?: string;
    notes?: string;
    notesIA?: string;        // Notes enrichissement IA
}
```

### Consultation

```typescript
interface Consultation {
    id: string;
    reference: string;       // Format: {NNN}CN-{AA}-R{X}
    objet: string;
    designation: string;
    navire?: string;
    ship_id?: string;        // UUID vers table ships
    client?: string;
    date_consultation: string;
    date_relance?: string;
    date_limite_depot?: string;
    lifecycleStatus?: ConsultationLifecycleStatus;
    supplierResponses: SupplierResponse[];
    masterPDR?: ComparisonItem[];
    attachments?: Attachment[];
}

type ConsultationLifecycleStatus =
    'En cours' | 'Relance' | 'Avec Offres' |
    'Infructueuse' | 'Annulée' | 'Clôturée';
```

### PurchaseOrder (Bon de commande)

```typescript
interface PurchaseOrder {
    id: string;
    reference: string;
    consultationId?: string;
    supplierId: string;
    status: POStatus;
    totalAmount?: number;
    currency?: string;
    paymentTerms?: string;
    incoterm?: string;
    date_prevue_livraison?: string;
    date_reception_reelle?: string;
    conformite?: 'conforme' | 'non_conforme' | 'partiel';
    details_non_conformite?: NonConformiteDetail[];
}

type POStatus = 'draft' | 'validation_pending' | 'sent' |
    'partial_receipt' | 'received' | 'cancelled';
```

### SupplierResponse (Réponse fournisseur)

```typescript
interface SupplierResponse {
    supplierId: string;
    status: 'En attente' | 'Offre reçue' | 'Accepté' |
        'Refusé' | 'Éliminé' | 'Négociation' | "Pas d'offre";
    offerAmount?: number;
    offerCurrency?: string;
    deliveryTime?: string;
    incoterm?: string;
    extractedData?: {
        items: ExtractedLineItem[];
        logistics: LogisticsInfo;
    };
    semanticMatches?: ItemMatch[];
    complianceScore?: number;
    risk_level?: 'low' | 'medium' | 'high' | 'critical';
}
```

## Types de suivi / Tracking Types

### DossierState

```typescript
interface DossierState {
    consultationId: string;
    currentStepId: string;
    lastUpdated: string;
    steps: WorkflowStep[];
    globalStatus: 'on_track' | 'delayed' | 'critical' | 'completed';
    completionPercentage: number;
}

interface WorkflowStep {
    id: string;
    label: string;
    status: 'pending' | 'in_progress' | 'completed' | 'error' | 'skipped';
    date?: string;
    notes?: string;
    isAutomated: boolean;
    subSteps?: WorkflowStep[];
}
```
