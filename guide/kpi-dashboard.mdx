## Présentation / Overview

Le **KPI Dashboard** offre une vue analytique approfondie de la performance de votre chaîne d'approvisionnement maritime. Il regroupe 8 modules d'analyse couvrant la performance livraison, les coûts, la conformité, les risques, et les cycles de traitement.

*The **KPI Dashboard** provides an in-depth analytical view of your maritime supply chain performance. It includes 8 analysis modules covering delivery performance, costs, compliance, risks, and processing cycles.*

## Modules d'analyse / Analysis Modules

### 1. Cartes de résumé / Summary Cards
Vue rapide des KPIs principaux : nombre total consultations, taux de réponse, budget engagé, délai moyen.

### 2. Performance Livraison / Delivery Performance
- **Taux OTD** (On-Time Delivery) — pourcentage de livraisons dans les délais
- **Tendance OTD** — graphique d'évolution mensuelle
- **Délai moyen** — écart entre date prévue et date réelle
- **Top retardataires** — fournisseurs avec les retards les plus fréquents

### 3. Analyse des Coûts / Cost Analysis
- **Économies réalisées** — différence entre prix estimé et prix payé
- **Évolution budgétaire** — graphique par période
- **Répartition par catégorie** de dépense
- **Coût moyen par consultation**

### 4. Conformité PDR / PDR Compliance
- **Taux de conformité global** — pièces conformes vs non conformes
- **Types de non-conformité** — distribution par type (référence, quantité, qualité)
- **Évolution** de la conformité dans le temps

### 5. Radar de Risque / Risk Radar
Graphique radar affichant les niveaux de risque sur 6 axes :
- Risque fournisseur, Risque logistique, Risque qualité, Risque financier, Risque délai, Risque documentation

### 6. Analyse Cycle / Cycle Time Analysis
- **Durée moyenne** du cycle consultation-commande
- **Goulots d'étranglement** identifiés
- **Temps de réponse** fournisseur moyen

### 7. Performance Fournisseurs / Supplier Performance
- Classement des fournisseurs par score global
- Taux de réponse par fournisseur
- Historique de conformité

### 8. Graphiques Financiers / Financial Charts
- Répartition des dépenses par devise
- Évolution des taux de change appliqués
- Montants par incoterm

## Fonctionnalités avancées / Advanced Features

- **Filtrage par période** — sélecteur de dates personnalisable
- **Filtrage par navire** — KPIs par navire spécifique
- **Export Excel** — exportez les données KPI en fichier Excel
- **Export PDF** — rapport KPI formaté pour impression
- **Alertes KPI** — notifications quand un indicateur passe sous le seuil configurable
