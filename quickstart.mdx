## Configuration de l'environnement / Environment Setup

Créez un fichier `.env.local` à la racine du projet et renseignez les variables suivantes :

*Create a `.env.local` file at the project root and fill in the following variables:*

```env
# Supabase
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key

# Google Gemini AI
GEMINI_API_KEY=your-gemini-api-key

# Email (SMTP/IMAP)
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your@email.com
SMTP_PASS=your-smtp-password
IMAP_HOST=imap.example.com
IMAP_PORT=993
```

<Warning>
Ajoutez `.env.local` à votre `.gitignore` pour ne jamais exposer vos clés secrètes.

*Add `.env.local` to your `.gitignore` to never expose your secret keys.*
</Warning>

## Initialisation de la base de données / Database Setup

Exécutez les scripts SQL dans votre tableau de bord Supabase (SQL Editor) dans cet ordre :

*Run the SQL scripts in your Supabase dashboard (SQL Editor) in this order:*

```sql
-- 1. Schéma principal
init_database.sql

-- 2. Schéma email
email_schema.sql

-- 3. Configuration SMTP
smtp_schema.sql

-- 4. Sécurité RLS
set_security.sql
```

## Démarrage en développement / Development Start

```bash
npm run dev
```

L'application sera accessible sur `http://localhost:5173` par défaut.

*The application will be accessible at `http://localhost:5173` by default.*

## Déploiement des Edge Functions / Deploy Edge Functions

```bash
supabase functions deploy ai-hub
supabase functions deploy comparison-engine
supabase functions deploy email-service
supabase functions deploy email-sync
supabase functions deploy verify-email
```
