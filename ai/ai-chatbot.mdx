## Présentation / Overview

L'**Assistant IA** de VesselIQ est un chatbot intelligent alimenté par Google Gemini, intégré directement dans l'application. Il assiste les utilisateurs dans leurs opérations quotidiennes, répond aux questions sur les données, et fournit des analyses contextuelles.

*VesselIQ's **AI Assistant** is an intelligent chatbot powered by Google Gemini, directly integrated into the application. It assists users in daily operations, answers data-related questions, and provides contextual analysis.*

---

## Fonctionnalités / Features

### 1. Chat contextuel / Contextual Chat

L'assistant comprend le contexte de l'application :
- **Données consultations** — résumés, statuts, montants
- **Fournisseurs** — informations, performances, historique
- **LC** — conformité UCP 600, conditions, risques

### 2. Assistant LC / LC Assistant

Intégré dans le module Lettres de Crédit :
- Analyse de conformité UCP 600 en temps réel
- Suggestions de clauses standard
- Détection de clauses ambiguës ou à risque
- Explication des articles UCP pertinents
- Génération de conditions adaptées au contexte

### 3. Analyse de documents / Document Analysis

L'assistant peut analyser :
- PDFs fournisseurs uploadés
- Résultats d'extraction IA
- Rapports de comparaison

### 4. Interface conversationnelle / Conversational Interface

- Messages avec formatage riche (markdown)
- Suggestions de questions pertinentes
- Historique de conversation
- Cartes d'erreur avec solutions proposées
